# Fresh Start Bakery - Website (Part 2)

## Overview
This project demonstrates the application of CSS styling and responsive design principles for the Fresh Start Bakery website. It builds upon Part 1 by improving typography, layout, and responsiveness across all pages.

## Changes Implemented

### 1. External Stylesheet
- Created and linked a single `style.css` file to all HTML pages
- Used consistent naming conventions and folder structure (`css/style.css`)

### 2. Base Styling
- Applied a warm bakery-themed color palette (yellows, browns, creams)
- Set default font family (Segoe UI, Tahoma, sans-serif) and line height for readability
- Added CSS reset for consistent rendering across browsers

### 3. Typography
- Styled headings (h1, h2, h3) with harmonious color and spacing
- Used relative units (em, %) for font sizes to ensure responsiveness

### 4. Layout Structure
- Implemented responsive media queries for mobile and tablet views
- Ensured navigation links stack vertically on smaller screens

### 5. Visual Styles
- Added gradients, shadows, and hover effects for interactive elements
- Styled forms with rounded corners and soft background colors

### 6. Responsive Design
- Used breakpoints at 768px and 480px for tablet and mobile layouts
- Adjusted font sizes, button widths, and navigation layout for smaller screens

### 7. Testing and Iteration
- Tested website using browser developer tools on desktop, tablet, and mobile
- Verified responsiveness and accessibility across Chrome, Edge, and Firefox
